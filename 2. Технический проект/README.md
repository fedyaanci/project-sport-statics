# Диаграммы C4

Пятая лабораторная работа. Три диаграммы описывают одну систему «Спортивная статистика» с разной подробностью. Архитектура основана на [требованиях](<../1. Исходные сведения/Архитектурные факторы.md>) и [ADR](../ADR/README.md).

## Границы и релизы

Показана целевая архитектура. Синие блоки доступны с MVP, светлые блоки с отметками R1 и R2 добавляются позже. В общих компонентах будущие функции указаны в описании.

- MVP: вход, права, соревнования, составы, матчи, протоколы, статистика и табло.
- R1: сравнения, позиции и прогресс, видео, материалы и архив.
- R2: прогноз, импорт, дополнительные регламенты и восстановление рабочей копии архива.

Одно Django-приложение формирует HTML и JSON. Его фоновые обработчики и служебные команды используют тот же проект и одну PostgreSQL. Файлы материалов и резервные комплекты показаны отдельными хранилищами.

## Как получить изображения

Исходники написаны на PlantUML с C4-PlantUML. SVG и PNG находятся в [out](<../out/2. Технический проект>). Библиотека C4 и иконки включены в `lib`, поэтому генерация после подготовки инструментов работает без загрузки библиотек из сети.

Для Windows x64 можно подготовить Java 17 и PlantUML в локальной папке `.tools`:

```powershell
& ".\2. Технический проект\setup-tools.ps1"
& ".\2. Технический проект\render.ps1"
```

Скрипт подготовки проверяет контрольные суммы загрузок, настраивает локальный предпросмотр VS Code и не меняет системный PATH. `.tools` и настройки с путями этого компьютера исключены из Git. На этом компьютере инструменты уже подготовлены. В VS Code можно открыть `.puml` и вызвать предпросмотр PlantUML через `Alt+D`.

При своей установке Java 17+ и PlantUML пути передаются в `render.ps1` параметрами `-JavaPath` и `-PlantUmlJar`. Проверенная версия генератора — PlantUML 1.2026.10. C4 DSL Extension рекомендован в настройках редактора; исходники этой работы имеют формат `.puml`.
