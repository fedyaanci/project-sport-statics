# Словарь

Здесь собраны термины проекта. Эти названия используются в требованиях, на доске и в дальнейшем коде.

## Пользователи и доступ

| Термин | Значение |
|---|---|
| Пользователь | Человек, который работает с приложением |
| Гость | Посетитель без активного сеанса. Может читать только публичные данные |
| Учётная запись | Данные для входа: почта, хеш пароля и состояние подтверждения |
| Сеанс | Доступ, открытый после успешного входа и ограниченный по времени |
| Аутентификация | Проверка личности пользователя при входе |
| Авторизация | Проверка права выполнить конкретное действие |
| Роль | Вид работы пользователя, например оператор или организатор |
| Область доступа | Турнир, команда или матч, для которых действует роль |
| Назначение доступа | Сохранённая связь пользователя, роли и области |
| Заявка доступа | Просьба выдать рабочую роль. Сама заявка права не даёт |
| Привязка профиля | Связь аккаунта со спортивным профилем игрока |
| Запрос сброса пароля | Одноразовый запрос с ограниченным сроком для установки нового пароля |
| Почтовое отправление | Запись о письме, попытках отправки и ответе почтового сервиса |

## Соревнование и игра

| Термин | Значение |
|---|---|
| Регламент | Правила допуска, составов, действий и расчёта показателей для выбранного спорта |
| Турнир | Соревнование, в котором может быть несколько сезонов |
| Сезон | Период турнира со своими участниками и матчами |
| Команда | Спортивный участник, объединяющий игроков |
| Игрок | Спортивный профиль человека. Его история сохраняется при смене команды |
| Сезонная заявка команды | Допущенная команда и список её игроков на сезон |
| Матч | Игра двух разных команд с расписанием, составами и историей действий |
| Состав матча | Игроки конкретной команды, выбранные для отдельного матча |
| Допуск | Разрешение участвовать в конкретном сезоне |
| Игровое время | Время внутри матча по правилам спорта. Отличается от календарного времени |
| Игровое действие | Принятый факт игры с типом, участниками и временем |
| Исправление действия | Новая версия принятого действия с причиной изменения |
| Отмена действия | Исключение действия из расчёта с сохранением записи и причины |
| Замена | Изменение участия игроков во время игры |
| Интервал участия | Отрезок времени, когда игрок находится в игре |
| Интервал позиции | Отрезок участия игрока на конкретной позиции |
| Показатель / метрика | Значение с определённой формулой, единицей и правилами расчёта |
| Выборка | Данные, подходящие под выбранные команды, игроков, даты и другие условия |
| Протокол матча | Сохранённые действия и показатели матча с номером версии |
| Редакция / версия | Сохранённый вариант данных. Подтверждение старой версии не подтверждает новую |
| Предварительный протокол | Данные по текущему ходу игры до официального утверждения |
| Итоговый протокол | Версия после завершения игры, которую проверяет организатор |
| Официальный протокол | Подтверждённая и опубликованная версия результата |
| Официальная корректировка | Разрешённое исправление опубликованного результата с новой проверкой |
| Публикация табло | Сохранённый доступ к текущим показателям матча для зрителей |

## Материалы и хранение

| Термин | Значение |
|---|---|
| Черновик | Уже сохранённый объект с автором и параметрами. Его можно открыть снова |
| Готовый результат | Сохранённое содержимое или файл, который можно просмотреть и опубликовать |
| Публикация | Размещение конкретной готовой версии материала в сервисе |
| Отчёт | Материал по сезону с параметрами, версией данных и файлом |
| Обзор | Текст журналиста о матче с выбранными фактами |
| Инфографика | Изображение с показателями и моментами команды |
| Прогноз | Оценка будущего матча по доступной истории, а не гарантированный результат |
| Срез данных | Момент, до которого разрешено использовать сведения в расчёте |
| Попытка обработки | Отдельный запуск подготовки результата существующего отчёта или видео |
| Ошибка обработки | Неудачная попытка с сохранённой причиной, которую можно разобрать и повторить |
| Отказ в прогнозе | Решение не рассчитывать прогноз из-за неподходящих или недостаточных данных |
| Видеомомент | Фрагмент готового видео, связанный с игровым действием |
| Пакет импорта | Сохранённые данные внешней базы вместе с результатом проверки |
| Сопоставление | Связь внешнего идентификатора с игроком или командой внутри приложения |
| Архив | Проверенный набор данных закрытого сезона для хранения истории |
| Рабочая копия архива | Восстановленные данные для разрешённого исправления. Исходный архив остаётся |
| Резервная копия | Копия базы и файлов для восстановления после сбоя |

## Термины требований

| Термин | Значение |
|---|---|
| Архитектурный фактор | Требование, ограничение или принцип, который влияет на устройство приложения |
| Функциональное требование | Что пользователь может сделать или получить |
| Нефункциональное требование | Какое качество требуется при заданных условиях |
| Агрегат | Данные и правила, которые нужно согласованно проверить и изменить |
| Ограниченный контекст | Область, внутри которой термины и правила имеют один согласованный смысл |
| Команда | Просьба изменить состояние. Она может быть отклонена |
| Запрос | Получение данных без изменения спортивного результата |
| Доменное событие | Значимый факт, который уже произошёл |
| Policy | Автоматическое действие в ответ на событие или наступивший срок |
| View в Event Storming | Экран или форма пользователя |
| Read Model | Данные, которые нужны для экрана или запроса |
| Django view | Обработчик веб-запроса. Это другое значение слова view |
| Идемпотентность | Повтор одной команды не создаёт дополнительный результат |
| Атомарность | Связанные изменения сохраняются вместе или не сохраняются вовсе |
| RPO | Допустимая потеря данных по времени после сбоя |
| RTO | Допустимое время восстановления работы |
| MVP | Первая версия, в которой можно полностью выполнить основную задачу пользователя |

## Важные различия

- Аккаунт нужен для входа, а профиль игрока хранит спортивные сведения.
- Сезонная заявка относится к сезону, состав матча — к отдельной игре.
- Завершение матча, подтверждение результата и публикация — разные действия.
- Передача письма SMTP-сервису ещё не означает доставку адресату.
- Нет данных и числовой ноль — разные результаты.
- Архив хранит историю сезона, резервная копия помогает восстановиться после сбоя.

## Состояния объектов

| Объект | Основные переходы |
|---|---|
| Матч | Запланирован → идёт → завершён. Запланированный матч можно отменить |
| Состав | Подан → подтверждён или возвращён → новая версия подана |
| Результат | Ожидает проверки → подтверждён. Возврат и официальная корректировка требуют новой проверки |
| Материал | Черновик → готов → опубликован. Для прогноза возможен отказ с причиной |
| Обработка | Текущая попытка → ошибка → новая попытка того же объекта |
| Импорт | Получен → проверен или обнаружен конфликт. После исправления нужна повторная проверка |
| Сезон | Открыт → закрыт. Восстановление копии не открывает сезон автоматически |

Общий подход к словарю описан в [Ubiquitous Language](https://martinfowler.com/bliki/UbiquitousLanguage.html). Значения терминов выше приняты для этого проекта.
