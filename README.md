# project-sport-statics

Документация проекта «Спортивная статистика». Приложение нужно для записи результатов матчей, просмотра статистики игроков и команд, подготовки отчётов и других материалов.

## Третья лабораторная

В работе описаны требования к приложению и основные термины:

- [Введение](<1. Исходные сведения/Введение.md>) — задача проекта, пользователи и функции.
- [Архитектурные факторы](<1. Исходные сведения/Архитектурные факторы.md>) — требования, ограничения и способы проверки.
- [Словарь](<1. Исходные сведения/Словарь.md>) — термины, которые используются в проекте.

Дополнительно:

- [Выбор стека](<Пояснения/Выбор стека.md>).
- [Краткое объяснение работы](<Пояснения/Как защитить.md>).

Основной стек: **Python, Django и PostgreSQL**. Для интерфейса используются HTML-шаблоны, CSS и немного JavaScript.
